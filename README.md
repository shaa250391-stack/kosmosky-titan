# Титановый глюкофон KOSMOSKY – сайт

Статический сайт без сборки: HTML, CSS, JS. Достаточно выложить содержимое папки на любой хостинг как есть.

## Страницы и языки
- `index.html` – английская версия (корень сайта: ссылка для международных аккаунтов).
- `ru.html` – русская версия (ссылка для русских аккаунтов, например `домен/ru.html`). Если нужен адрес `/ru` без «.html» – правило на хостинге.
- Переключатель RU / EN в шапке ведёт между этими двумя страницами.

## Перед запуском на домене
1. Убрать из обеих страниц строку `<meta name="robots" content="noindex">` – она стоит только для тестовой ссылки, чтобы поисковики её не индексировали.
2. Ссылки-заглушки `https://kosmosky.example/titan` (кнопки «Order / Заказать») и `https://kosmosky.example/instagram` заменим на настоящие до передачи.
3. Превью ссылки (картинка Open Graph) и фавикон – добавим, когда будут файлы.
4. Аналитику подключает тот, кто выкладывает (код вставляется перед `</head>` в обе страницы).

## Что внутри
- `styles/` – `tokens.css` (переменные), `site.css` (стили), `fonts.css` (шрифты).
- `js/site.js` – логика и анимации обеих версий (язык определяется по `<html lang>`).
- `assets/fonts/` – шрифты (Geist, Onest, Apfel Grotezk) локально, лицензии в `SOURCES.md` исходного проекта: SIL OFL 1.1.
- `assets/img`, `assets/video`, `assets/audio` – картинки, видео, звук.
- Внешние ресурсы: только библиотеки анимации с jsDelivr – GSAP 3.15.0 (ScrollTrigger, SplitText) и Lenis 1.3.26 (адреса в `<head>`).
- Кэш: у файлов стилей и скрипта в адресе стоит `?v=N`; после замены файлов N увеличивается, чтобы браузеры взяли новую версию.

Тексты и вёрстку правим в исходном проекте, русская страница собирается из английской скриптом; эту папку руками лучше не править.
